* \rontend/\ - The React/Vite interactive meteorological HUD.

## Getting Started

### Backend
1. Navigate to \ackend/\
2. Create a virtual environment: \python -m venv venv\
3. Activate the environment and install dependencies: \pip install -r requirements.txt\
4. Run the server: \uvicorn app.main:app --reload\ (Runs on port 8000)

### Frontend
1. Navigate to \rontend/\
2. Install dependencies: \
pm install\
3. Start the Vite dev server: \
pm run dev\ (Runs on port 5173)
